# Upstream attribution and local modifications

The historical node-cache fixture includes source derived from upstream node-cache 3.2.1 and 4.0.0. The upstream LICENSE files are retained with corresponding sources, under MIT, including Copyright (c) 2016 mpneuried. The 4.0.0 README retains a separate attribution to Mathias Peter (2013).

The original CoffeeScript and several source/test files and license files were compared to pinned upstream commits; the entire fixture trees should not be described as exact upstream copies. Local JavaScript files are generated build outputs, package metadata differs, and the suite has some line-ending differences. See `docs/UPSTREAM-ATTRIBUTION.node-cache.md` for verified hashes and details.

The equivalent and survivor controls are local illustrative test implementations, not copied node-cache source. These materials are kept for historical reproducibility and carry their respective upstream notices.
